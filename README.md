# Enterprise Network Routing & Switching Project

Cisco Packet Tracer enterprise network project implementing RIP routing, VLANs, Inter-VLAN routing, DHCP, EtherChannel, and ACL security.

## 🔧 Technologies Used

* Cisco Packet Tracer
* RIP v2 Routing
* VLAN Configuration
* Inter-VLAN Routing
* DHCP
* EtherChannel (LACP)
* ACL Security
* TCP/IP Networking

## 🌐 Features

* Sydney and Melbourne branch connectivity
* VLAN segmentation for departments
* Dynamic IP allocation using DHCP
* Router-on-a-stick configuration
* EtherChannel redundancy and bandwidth optimisation
* Secure communication using ACLs
